# Diana Shimon Gallery

A modern art gallery website built with Next.js 14, showcasing Diana Shimon's artwork collection.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Shadcn UI
- React Server Components
- Server Actions

## Features

- Responsive image gallery
- Art collections categorization
- Contact form
- About the artist
- Exhibition information
- Image optimization with Next.js Image
- SEO optimization

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Nivben190/diana-shimon-gallery-nextjs.git

# Install dependencies
npm install

# Run the development server
npm run dev
```

## Project Structure

```
src/
├── app/                    # App Router pages
├── components/            # Reusable components
│   ├── ui/               # Shadcn UI components
│   └── gallery/          # Gallery-specific components
├── lib/                  # Utility functions
├── types/               # TypeScript types
└── styles/              # Global styles
```
